# Гайд по заполнению lessons.csv

После каждого демо-урока открыть `data/lessons.csv` и добавить строку снизу.
Разделитель — точка с запятой `;`.

## Поля

| Поле | Формат | Пример |
|---|---|---|
| date | ГГГГ-ММ-ДД | 2026-06-01 |
| child_name | Имя ребёнка | Максим |
| age | Число | 10 |
| parent_name | Имя родителя | Светлана |
| parent_role | мама / папа / оба / опекун | мама |
| lpr_present | да / нет | да |
| child_engagement | 1–5 | 4 |
| parent_interest | 1–5 | 5 |
| course | НейроТин / Python / другое | НейроТин |
| tech_issues | да / нет | нет |
| objection_category | см. ниже | финансы |
| objection_text | Свободный текст | Дорого не готов |
| result | продано / отказ / follow-up | follow-up |
| followup_date | ГГГГ-ММ-ДД или пусто | 2026-08-01 |
| comment | Свободный текст | Тёплый контакт |

## Категории возражений

| Значение | Когда ставить |
|---|---|
| `нет` | Возражений не было — просто купили |
| `сезонность` | Уезжают / нет интернета / «с сентября» |
| `финансы` | Дорого / ЯС отказал / банкротство |
| `нет_ЛПР` | Решает тот кого не было на уроке |
| `нет_мотивации` | Ребёнок не хочет / другие интересы |
| `не_определено` | Интерес есть но решения нет — непонятно почему |

## Шкала оценок

**child_engagement — вовлечённость ребёнка:**
- 5 — в восторге хотел продолжать
- 4 — активно участвовал
- 3 — нейтрально
- 2 — вялый без интереса
- 1 — сопротивлялся отказывался

**parent_interest — интерес родителя:**
- 5 — сам спрашивал про оплату и программу
- 4 — задавал вопросы слушал
- 3 — присутствовал нейтрально
- 2 — скептичен мало вовлечён
- 1 — негативно настроен
