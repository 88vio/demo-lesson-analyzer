# Demo Lesson Analyzer

Инструмент для анализа результатов демо-уроков по детским IT-курсам. Читает таблицу уроков, считает конверсию и формирует готовый markdown-отчёт.

![скрин гл](images/Снимок%20экрана%202026-06-03%20163651.png)
---

## Задача

Преподаватель отдела продаж проводит демо-уроки и вручную вносит итоги в CSV. Нужно быстро получить срез: сколько продано, какие возражения мешают, кому просрочен follow-up.

## Пользователь

Менеджер / преподаватель продаж детских IT-курсов (НейроТин, Python).

## Основная функция

Запустить одну команду → получить отчёт:

```bash
node scripts/analyze.js
# или
python scripts/analyze.py
```
![скрин гл](images/Снимок%20экрана%202026-06-03%20164651.png)

Отчёт сохраняется в `reports/ДАТА_отчёт.md` и выводится в терминал.

## Формат результата

Markdown-файл с четырьмя блоками:

| Блок | Что показывает |
|---|---|
| Шапка | Всего уроков, продано, общая конверсия % |
| По категории возражения | Продано / отказ / follow-up + конверсия по каждому типу |
| Влияние ЛПР | Конверсия когда ЛПР был на уроке vs не был |
| Средние оценки | child\_engagement и parent\_interest по итогу урока |
| Просроченные follow-up | Список контактов которым нужно позвонить сегодня |
| Активные follow-up | Список запланированных follow-up с датами |

## Поля таблицы lessons.csv

Разделитель — `;`. После каждого урока добавляется одна строка.

| Поле | Формат | Пример |
|---|---|---|
| date | ГГГГ-ММ-ДД | 2026-06-01 |
| child\_name | Имя ребёнка | Максим |
| age | Число | 10 |
| parent\_name | Имя родителя | Светлана |
| parent\_role | мама / папа / оба / опекун | мама |
| lpr\_present | да / нет | да |
| child\_engagement | 1–5 | 4 |
| parent\_interest | 1–5 | 5 |
| course | НейроТин / Python / другое | НейроТин |
| tech\_issues | да / нет | нет |
| objection\_category | финансы / сезонность / нет\_ЛПР / нет\_мотивации / не\_определено / нет | финансы |
| objection\_text | Свободный текст | Дорого не готов |
| result | продано / отказ / follow-up | follow-up |
| followup\_date | ГГГГ-ММ-ДД или пусто | 2026-08-01 |
| comment | Свободный текст | Тёплый контакт |

## Технологии

- **Node.js** — основная версия, зависимостей нет, запускается сразу
- **Python 3 + pandas + tabulate** — альтернативная версия (`pip install -r requirements.txt`)

## Минимальный запуск

```bash
# Node.js (рекомендуется)
node scripts/analyze.js

# Python
pip install -r requirements.txt
python scripts/analyze.py
```
