# Demo Lesson Analyzer — рабочий скилл

## Структура проекта

```
Final_Project/
├── data/
│   └── lessons.csv          # Основная таблица. Разделитель — ; (точка с запятой)
├── scripts/
│   ├── analyze.js           # Node.js-версия (без зависимостей, запускать в первую очередь)
│   └── analyze.py           # Python-версия (требует pandas + tabulate)
├── reports/
│   └── ДАТА_отчёт.md        # Генерируются автоматически при каждом запуске
├── templates/
│   └── comment_guide.md     # Гайд по полям таблицы и шкале оценок
├── images/                  # Скриншоты для README
├── requirements.txt         # pandas, tabulate
└── README.md
```

## Как запускать анализ

```bash
# Node.js (рекомендуется — нет зависимостей)
node scripts/analyze.js

# Python
pip install -r requirements.txt
python scripts/analyze.py
```

Отчёт сохраняется в `reports/ГГГГ-ММ-ДД_отчёт.md` и выводится в терминал.

## Структура таблицы lessons.csv

Разделитель — `;`. Кодировка UTF-8. Одна строка = один демо-урок.

| Поле | Допустимые значения |
|---|---|
| date | ГГГГ-ММ-ДД |
| child_name | Имя ребёнка |
| age | Целое число |
| parent_name | Имя родителя |
| parent_role | мама / папа / оба / опекун |
| lpr_present | да / нет |
| child_engagement | 1–5 |
| parent_interest | 1–5 |
| course | НейроТин / Python / другое |
| tech_issues | да / нет |
| objection_category | нет / финансы / сезонность / нет_ЛПР / нет_мотивации / не_определено |
| objection_text | Свободный текст (можно пусто) |
| result | продано / отказ / follow-up |
| followup_date | ГГГГ-ММ-ДД или пусто |
| comment | Свободный текст (можно пусто) |

## Задачи и как их выполнять

### Добавить новый урок

1. Прочитать `data/lessons.csv`
2. Добавить строку снизу, соблюдая порядок полей и разделитель `;`
3. Не менять заголовок и существующие строки
4. Запустить `node scripts/analyze.js` для проверки

### Запустить анализ и показать отчёт

```bash
node scripts/analyze.js
```

Вывести результат пользователю как markdown.

### Проверить ошибки в таблице

Признаки битой строки:
- Неверное количество полей (должно быть 15)
- result не из списка: `продано / отказ / follow-up`
- objection_category не из допустимых значений
- lpr_present не `да` / `нет`
- followup_date заполнена, но result не `follow-up`
- child_engagement или parent_interest вне диапазона 1–5

Проверять командой:
```bash
node scripts/analyze.js
```
Если скрипт упал — читать стек ошибки и находить проблемную строку в CSV.

## Частые ошибки

| Симптом | Причина | Решение |
|---|---|---|
| Картинка не отображается в README | Вложенный синтаксис `![alt]([text](url))` | Заменить на `![alt](путь)` |
| Скрипт крашится на CSV | Лишний разделитель или кавычка в тексте | Найти строку, убрать `;` внутри текстовых полей |
| follow-up без даты | followup_date пустая при result=follow-up | Добавить дату или оставить пустой — скрипт обработает как "активный без даты" |
| Отчёт не генерируется | Нет папки reports/ | Скрипт создаёт её автоматически — проверить права на запись |
